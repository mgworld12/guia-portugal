# Guia de Portugal
Site estático (HTML, CSS e JS) sobre Portugal: turismo e vida prática. Funciona como PWA (instalável no Android).

- `data.js`: todo o conteúdo. Para adicionar um item, copie um bloco `{n:...,d:...}` dentro da seção desejada.
- `app.js`: gera as páginas, a busca e o tema claro/escuro.
- `style.css`: visual. `sw.js` e `manifest.webmanifest`: PWA e modo offline.

Publicação: GitHub Pages (Settings > Pages > Deploy from a branch > main / root).
